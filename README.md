SMS Spam Detection Using Machine Learning

Project Overview

SMS Spam Detection is a machine learning project that classifies SMS messages as either Spam or Ham (Not Spam).

The project uses natural language processing and machine learning techniques to analyze the text of SMS messages and predict whether a message is spam.

Objectives

- Detect spam SMS messages automatically.
- Preprocess and clean text data.
- Convert text into numerical features.
- Train machine learning classification models.
- Evaluate the performance of the models.
- Predict whether a new SMS message is spam or not spam.

Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Natural Language Processing (NLP)

Machine Learning

The dataset contains SMS messages labeled as:

- Ham
- Spam

The text data is preprocessed before training the machine learning model.

Project Workflow

1. Import the dataset
2. Explore the dataset
3. Clean and preprocess the SMS text
4. Convert text into numerical features
5. Split the dataset into training and testing data
6. Train machine learning models
7. Evaluate the models
8. Test the model with new SMS messages

Results

The trained machine learning model can classify SMS messages into spam and non-spam categories.

How to Run the Project

1. Clone this repository.
2. Open the Jupyter Notebook.
3. Install the required Python libraries.
4. Run the notebook cells in order.
5. Enter SMS messages to test the prediction.

Future Scope

The project can be extended by:

- Using larger SMS datasets.
- Testing additional machine learning algorithms.
- Improving text preprocessing.
- Developing a web-based interface.
- Deploying the model as an application.
